<div class="verse-block-wrapper" id="uma-maheshvara-puja-b0002"><div class="verse-block verse-justify"><div class="line">शुक्लाम्बरधरं विष्णुं शशिवर्णं चतुर्भुजम्।</div><div class="line" style="position:relative;">प्रसन्नवदनं ध्यायेत् सर्वविघ्नोपशान्तये॥</div></div></div>

<h3 class="subheading">सङ्कल्पः</h3>
<p class="prose">ममोपात्त-समस्त-दुरित-क्षयद्वारा श्री-परमेश्वर-प्रीत्यर्थं शुभे शोभने मुहूर्ते अद्य ब्रह्मणः द्वितीयपरार्धे श्वेतवराहकल्पे वैवस्वतमन्वन्तरे अष्टाविंशतितमे कलियुगे प्रथमे पादे जम्बूद्वीपे भारतवर्षे भरतखण्डे मेरोः दक्षिणे पार्श्वे शकाब्दे अस्मिन् वर्तमाने व्यावहारिकाणां प्रभवादीनां षष्ट्याः संवत्सराणां मध्ये ( ) नाम संवत्सरे ( ) ( )-ऋतौ ( )-मासे (शुक्ल / कृष्ण)पक्षे ( ) शुभतिथौ (इन्दु / भौम / सौम्य / गुरु / भृगु / स्थिर / भानु)-वासरयुक्तायां ( )-नक्षत्र-( )-योग-( )-करण-युक्तायां च एवं गुण-विशेषण-विशिष्टायाम् अस्याम्<br>( ) शुभतिथौ अस्माकं सहकुटुम्बानां क्षेमस्थैर्य-धैर्य-वीर्य-विजय-आयुरारोग्य-ऐश्वर्याभिवृद्ध्यर्थं धर्मार्थकाममोक्षचतुर्विधफलपुरुषार्थसिद्ध्यर्थं पुत्रपौत्राभिवृद्ध्यर्थम् इष्टकाम्यार्थसिद्ध्यर्थं मम इहजन्मनि पूर्वजन्मनि जन्मान्तरे च सम्पादितानां ज्ञानाज्ञानकृतमहापातकचतुष्टय-व्यतिरिक्तानां रहस्यकृतानां प्रकाशकृतानां सर्वेषां पापानां सद्य अपनोदनद्वारा सकल-पापक्षयार्थं श्री-उमामहेश्वर-प्रसादसिद्ध्यर्थं यथाशक्ति-ध्यान-आवाहनादि-षोडशोपचारैः श्री-उमामहेश्वरपूजां करिष्ये।<br>तदङ्गं कलशपूजां च करिष्ये।<br>श्रीविघ्नेश्वराय नमः यथास्थानं प्रतिष्ठापयामि। शोभनार्थे क्षेमाय पुनरागमनाय च।<br>(गणपति-प्रसादं शिरसा गृहीत्वा)</p>

<div class="verse-block-wrapper" id="uma-maheshvara-puja-b0066"><div class="verse-block verse-justify"><div class="line">गृहाण भक्तवरदे लक्ष्मीवाण्यादिसेविते।</div><div class="line" style="position:relative;">साज्यं त्रिवर्तिविस्फूर्जद्दीपं शिव शिवापते॥</div></div></div>
<div class="verse-block-wrapper" id="uma-maheshvara-puja-b0067"><div class="verse-block verse-justify"><div class="line">गृहाणानन्तसूर्याग्निचन्द्रप्रभ नमोऽस्तु ते।</div><div class="line" style="position:relative;">साज्यं त्रिवर्तिविस्पूर्जद्दीपमीशानवल्लभे॥</div></div></div>
<p class="prose">एष दीपः ॐ उमामहेश्वराभ्यां नमः।</p>
<div class="verse-block-wrapper" id="uma-maheshvara-puja-b0069"><div class="verse-block verse-justify"><div class="line">गृहाण चन्द्रसूर्याग्निमण्डलाधिकसुप्रभे।</div><div class="line" style="position:relative;">शम्भो गोघृतसंयुक्तं परमान्नं मनोहरम्॥</div></div></div>

<div class="verse-block-wrapper" id="uma-maheshvara-puja-b0076"><div class="verse-block verse-justify"><div class="line">नीराजनं गृहाणाम्ब सूर्यचन्द्राग्निलोचने।</div><div class="line" style="position:relative;">प्रभापूरित सर्वाङ्गे मङ्गले मङ्गलास्पदे॥</div></div></div>
