<h3 class="subheading">सङ्कल्पः</h3>
<p class="prose">ममोपात्त-समस्त-दुरित-क्षयद्वारा श्री-परमेश्वर-प्रीत्यर्थं शुभे शोभने मुहूर्ते अद्य ब्रह्मणः<br>द्वितीयपरार्धे श्वेतवराहकल्पे वैवस्वतमन्वन्तरे अष्टाविंशतितमे कलियुगे प्रथमे पादे<br>जम्बूद्वीपे भारतवर्षे भरतखण्डे मेरोः दक्षिणे पार्श्वे शकाब्दे अस्मिन् वर्तमाने व्यावहारिकाणां<br>प्रभवादीनां षष्टिसंवत्सराणां मध्ये ( ) नाम संवत्सरे उत्तरायणे / दक्षिणायने<br>(ग्रीष्म / वर्ष / शरद् / हेमन्त / शिशिर / वसन्त) ऋतौ (मेष / वृषभ / मिथुन / कर्कटक / सिंह / कन्या / तुला /<br>वृश्चिक / धनुर् / मकर / कुम्भ / मीन) मासे (शुक्ल / कृष्ण) पक्षे (एकादश्यां / द्वादश्यां) शुभतिथौ<br>(इन्दु / भौम / सौम्य / गुरु / भृगु / स्थिर / भानु)-वासरयुक्तायाम्<br>( ) नक्षत्र ( ) नाम योग ( )-करण-युक्तायां च एवं गुण विशेषण विशिष्टायाम्<br>अस्यां ( ) शुभतिथौ<br>अस्माकं सहकुटुम्बानां क्षेमस्थैर्य-धैर्य-वीर्य-विजय-आयुरारोग्य-ऐश्वर्याभिवृद्ध्यर्थम्<br>धर्मार्थकाममोक्षचतुर्विधफलपुरुषार्थसिद्ध्यर्थं पुत्रपौत्राभिवृद्ध्यर्थम् इष्टकाम्यार्थसिद्ध्यर्थम्<br>मम इहजन्मनि पूर्वजन्मनि जन्मान्तरे च सम्पादितानां ज्ञानाज्ञानकृतमहापातकचतुष्टय-व्यतिरिक्तानां रहस्यकृतानां प्रकाशकृतानां सर्वेषां पापानां सद्य अपनोदनद्वारा सकल पापक्षयार्थं<br>श्री-महागणपति-प्रीत्यर्थं श्री-छाया-सुवर्चलाम्बा-समेत-श्री-सूर्यनारायण-प्रीत्यर्थं श्री-लक्ष्मीनारायण-प्रीत्यर्थं<br>श्री-महालक्ष्मीसमेतं श्री-सन्तानगोपाल-प्रीत्यर्थं श्री-गौरीदेवी-प्रीत्यर्थं श्री-साम्बपरमेश्वर-प्रीत्यर्थं श्री-नन्दिकेश्वर-प्रीत्यर्थं<br>श्री-वल्लीदेवसेनासमेत-श्री-सुब्रह्मण्य-प्रीत्यर्थं श्री-सीता-लक्ष्मण-भरत-शत्रुघ्न-हनूमत्-समेत-श्री-रामचन्द्र-प्रीत्यर्थं<br>यावच्छक्ति ध्यानावाहनादि षोडशोपचार-पूजां पञ्चायतनपूजां क्षीराभिषेकं च करिष्ये। तदङ्गं कलशपूजां च करिष्ये।<br>श्रीविघ्नेश्वराय नमः यथास्थानं प्रतिष्ठापयामि।<br>(गणपति-प्रसादं शिरसा गृहीत्वा)<br>[संस्काररत्नमालायां पार्थिवलिङ्गपूजनविधौ] लैङ्गे—</p>
<div class="verse-block-wrapper" id="laghu-panchayatana-puja-b0005"><div class="verse-block verse-justify"><div class="line">विना भस्मत्रिपुण्ड्रेण विना रुद्राक्षमालया।</div><div class="line" style="position:relative;">पूजितोऽपि महादेवो न स्यात्तस्य फलप्रदः॥</div></div></div>
<p class="prose">रुद्राक्षमालां धृत्वा।</p>
<h2 class="stotra-heading">षोडशोपचार-पूजा</h2>
<p class="prose">ॐ ग॒णानां᳚ त्वा ग॒णप॑तिꣳ हवामहे क॒विं क॑वी॒नामु॑प॒मश्र॑वस्तमम्।<br>ज्ये॒ष्ठ॒राजं॒ ब्रह्म॑णां ब्रह्मणस्पत॒ आ नः॑ शृ॒ण्वन्नू॒तिभिः॑ सीद॒ साद॑नम्॥<br>ॐ महागणपतये॒ नमः॥<br>अस्मिन् बिम्बे श्री-महागणपतिं ध्यायामि। आवाहयामि॥<br>आ स॒त्येन॒ रज॑सा॒ वर्त॑मानो निवे॒शय॑न्न॒मृतं॒ मर्त्यं॑ च। हि॒र॒ण्यये॑न सवि॒ता रथे॒नाऽदे॒वो या॑ति॒ भुव॑ना वि॒पश्यन्॑।<br>अस्मिन् बिम्बे श्री-छाया-सुवर्चलाम्बा-समेत-श्री-सूर्यनारायणं ध्यायामि। आवाहयामि॥<br>स॒हस्र॑शीर्‌षा॒ पुरु॑षः। स॒ह॒स्रा॒क्षः स॒हस्र॑पात्।<br>स भूमिं॑ वि॒श्वतो॑ वृ॒त्वा। अत्य॑तिष्ठद्दशाङ्गु॒लम्॥<br>हिर॑ण्यवर्णां॒ हरि॑णीं सुव॒र्णर॑जत॒स्रजाम्।<br>च॒न्द्रां॒ हि॒रण्म॑यीं ल॒क्ष्मीं॒ जात॑वेदो म॒ आव॑ह॥<br>अस्मिन् बिम्बे श्री-लक्ष्मीनारायणं ध्यायामि।<br>अस्मिन् बिम्बे श्री-महालक्ष्मीसमेतं श्री-सन्तानगोपालं ध्यायामि।<br>त्र्य॑म्बकं यजामहे सुग॒न्धिं पु॑ष्टि॒वर्ध॑नम्।<br>उ॒र्वा॒रु॒कमि॑व॒ बन्ध॑नान्मृ॒त्योर्मु॑क्षीय॒ माऽमृता᳚त्॥<br>गौ॒री मि॑माय सलि॒लानि॒ तक्ष॒ती। एक॑पदी द्वि॒पदी॒ सा चतु॑ष्पदी।<br>अ॒ष्टाप॑दी॒ नव॑पदी बभू॒वुषी। स॒हस्रा᳚क्षरा पर॒मे व्यो॑मन्।<br>अस्मिन् बिम्बे श्री-सपरिवार-साम्बपरमेश्वरं ध्यायामि। आवाहयामि॥<br>अस्मिन् बिम्बे श्री-गौरीदेवीं ध्यायामि। आवाहयामि॥<br>अस्मिन् बिम्बे श्री-साम्बपरमेश्वरं ध्यायामि। आवाहयामि॥<br>तत्पुरु॑षाय वि॒द्महे॑ चक्रतु॒ण्डाय॑ धीमहि। तन्नो॑ नन्दिः प्रचो॒दया᳚त्।<br>अस्मिन् बिम्बे श्री-नन्दिकेश्वरं ध्यायामि। आवाहयामि॥<br>तत्पुरु॑षाय वि॒द्महे॑ महासे॒नाय॑ धीमहि। तन्नः॑ षण्मुखः प्रचो॒दया᳚त्॥<br>अस्मिन् बिम्बे श्री-वल्लीदेवसेनासमेत-श्री-सुब्रह्मण्यस्वामिनं ध्यायामि।</p>

<p class="prose">अस्मिन् बिम्बे श्री-सीता-लक्ष्मण-भरत-शत्रुघ्न-हनूमत्-समेत-श्री-रामचन्द्रं ध्यायामि।</p>

<p class="prose">आवाहयामि॥<br>आवाहिताभ्यः सर्वाभ्यो-देवताभ्यो नमः।<br>आसनं समर्पयामि।<br>पादयोः पाद्यं समर्पयामि।<br>अर्घ्यं समर्पयामि।<br>आचमनीयं समर्पयामि।<br>शुद्धोदकस्नानं समर्पयामि। स्नानानन्तरम् आचमनीयं समर्पयामि।</p>
<h3 class="subheading">अभिषेकः</h3>
<p class="prose">ॐ ग॒णानां᳚ त्वा ग॒णप॑तिꣳ हवामहे क॒विं क॑वी॒नामु॑प॒मश्र॑वस्तमम्।<br>ज्ये॒ष्ठ॒राजं॒ ब्रह्म॑णां ब्रह्मणस्पत॒ आ नः॑ शृ॒ण्वन्नू॒तिभिः॑ सीद॒ साद॑नम्॥<br>ॐ महागणपतये॒ नमः॥<br>ॐ आ स॒त्येन॒ रज॑सा॒ वर्त॑मानो निवे॒शय॑न्न॒मृतं॒ मर्त्यं॑ च। हि॒र॒ण्यये॑न सवि॒ता रथे॒नाऽदे॒वो या॑ति॒ भुव॑ना वि॒पश्यन्॑।<br>ॐ स॒हस्र॑शीर्‌षा॒ पुरु॑षः। स॒ह॒स्रा॒क्षः स॒हस्र॑पात्।<br>स भूमिं॑ वि॒श्वतो॑ वृ॒त्वा। अत्य॑तिष्ठद्दशाङ्गु॒लम्॥<br>ॐ हिर॑ण्यवर्णां॒ हरि॑णीं सुव॒र्णर॑जत॒स्रजाम्।<br>च॒न्द्रां॒ हि॒रण्म॑यीं ल॒क्ष्मीं॒ जात॑वेदो म॒ आव॑ह॥<br>गौ॒री मि॑माय सलि॒लानि॒ तक्ष॒ती। एक॑पदी द्वि॒पदी॒ सा चतु॑ष्पदी।<br>अ॒ष्टाप॑दी॒ नव॑पदी बभू॒वुषी। स॒हस्रा᳚क्षरा पर॒मे व्यो॑मन्।<br>तत्पुरु॑षाय वि॒द्महे॑ चक्रतु॒ण्डाय॑ धीमहि। तन्नो॑ नन्दिः प्रचो॒दया᳚त्।<br>तत्पुरु॑षाय वि॒द्महे॑ महासे॒नाय॑ धीमहि। तन्नः॑ षण्मुखः प्रचो॒दया᳚त्॥<br>ॐ नमो भगवते॑ रुद्रा॒य॥<br>रुद्रप्रश्न-चमकप्रश्न-पुरुषषुक्तैः अभिषेकं कृत्वा।<br>अभिषेकानन्तरं आचमनीयं समर्पयामि। वस्त्रार्थम् अक्षतान् समर्पयामि। यज्ञोपवीताभरणार्थे अक्षतान् समर्पयामि।<br>दिव्यपरिमलगन्धान् धारयामि। गन्धस्योपरि हरिद्राकुङ्कुमं समर्पयामि। अक्षतान् समर्पयामि।<br>पुष्पमालिकां समर्पयामि। पुष्पैः पूजयामि।</p>
<h3 class="subheading">महागणपति-अर्चना</h3>

<h3 class="subheading">नमस्कारमन्त्राः</h3>
<p class="prose">नमो हिरण्यबाहवे हिरण्यवर्णाय हिरण्यरूपाय हिरण्यपतयेऽम्बिकापतय उमापतये पशुपतये॑ नमो॒ नमः॥<br>ऋ॒तꣳ स॒त्यं प॑रं ब्र॒ह्म॒ पु॒रुषं॑ कृष्ण॒पिङ्ग॑लम्।<br>ऊ॒र्ध्वरे॑तं वि॑रूपा॒क्षं॒ वि॒श्वरू॑पाय॒ वै नमो॒ नमः॑॥<br>सर्वो॒ वै रु॒द्रस्तस्मै॑ रु॒द्राय॒ नमो॑ अस्तु।<br>पुरु॑षो॒ वै रु॒द्रः सन्म॒हो नमो॒ नमः॑।<br>विश्वं॑ भू॒तं भुव॑नं चि॒त्रं ब॑हु॒धा जा॒तं जाय॑मानं च॒ यत्।<br>सर्वो॒ ह्ये॑ष रु॒द्रस्तस्मै॑ रु॒द्राय॒ नमो॑ अस्तु॥<br>कद्रु॒द्राय॒ प्रचे॑तसे मी॒ढुष्ट॑माय॒ तव्य॑से।<br>वो॒ चेम॒ शन्त॑मꣳ हृ॒दे।<br>सर्वो॒ ह्ये॑ष रु॒द्रस्तस्मै॑ रु॒द्राय॒ नमो॑ अस्तु॥<br>अनन्तकोटिप्रदक्षिणनमस्कारान् समर्पयामि। नमस्कारान् कृत्वा।छत्त्र-चामर-नृत्त-गीत-वाद्य-समस्त-राजोपचारान् समर्पयामि।</p>

<h3 class="subheading">उद्वासनम्</h3>
<p class="prose">निर्याणमुद्रया पुष्पाण्यादाय आघ्राय हृदये स्थापयित्वा उद्वासयेत्। निर्माल्यं शिरसि धारयेत्।</p>
