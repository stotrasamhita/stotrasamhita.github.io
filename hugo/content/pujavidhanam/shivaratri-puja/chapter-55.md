<div class="stotra-article"><h2 class="stotra-heading">प्रधान-पूजा — साम्ब-परमेश्वर-पूजा (चतुर्थ-यामः)</h2>
<div class="verse-block-wrapper" id="shivaratri-puja-b0979"><div class="verse-block verse-justify"><div class="line">शुक्लाम्बरधरं विष्णुं शशिवर्णं चतुर्भुजम्।</div><div class="line" style="position:relative;">प्रसन्नवदनं ध्यायेत् सर्वविघ्नोपशान्तये॥</div></div></div>
<p class="prose">प्राणान् आयम्य। ॐ भूः + भूर्भुवः॒ सुव॒रोम्।<br>ममोपात्त-समस्त-दुरित-क्षयद्वारा श्री-परमेश्वर-प्रीत्यर्थं शुभे शोभने मुहूर्ते अद्य ब्रह्मणः<br>द्वितीयपरार्धे श्वेतवराहकल्पे वैवस्वतमन्वन्तरे अष्टाविंशतितमे कलियुगे प्रथमे पादे<br>जम्बूद्वीपे भारतवर्षे भरतखण्डे मेरोः दक्षिणे पार्श्वे शकाब्दे अस्मिन् वर्तमाने व्यावहारिकणां<br>प्रभवादि षष्ट्याः संवत्सराणां मध्ये ( ) नाम संवत्सरे उत्तरायणे<br>शिशिर-ऋतौ कुम्भ-मासे कृष्ण-पक्षे त्र्योदश्यां/चतुर्दश्यां शुभतिथौ<br>(इन्दु / भौम / बुध / गुरु / भृगु / स्थिर / भानु)-वासरयुक्तायाम्<br>( ) नक्षत्र ( )-योग ( )-करण-युक्तायां च एवं गुण विशेषण विशिष्टायाम्<br>अस्याम् (त्र्योदश्यां/चतुर्दश्यां) शुभतिथौ<br>अस्माकं सहकुटुम्बानां क्षेमस्थैर्य-धैर्य-वीर्य-विजय-आयुरारोग्य-ऐश्वर्याभिवृद्ध्यर्थम्<br>धर्मार्थकाममोक्षचतुर्विधफलपुरुषार्थसिद्ध्यर्थं पुत्रपौत्राभिवृद्ध्यर्थम् इष्टकाम्यार्थसिद्ध्यर्थम्<br>मम इहजन्मनि पूर्वजन्मनि जन्मान्तरे च सम्पादितानां ज्ञानाज्ञानकृतमहापातकचतुष्टय-व्यतिरिक्तानां रहस्यकृतानां प्रकाशकृतानां सर्वेषां पापानां सद्य अपनोदनद्वारा सकल-पापक्षयार्थं शिवरात्रौ श्री-साम्ब-परमेश्वर-प्रीत्यर्थं चतुर्थ-यामपूजां करिष्ये।</p></div>
