*Last updated: 15 October 2026*

This policy covers Stotra Samhita (https://stotrasamhita.github.io/) and the Stotra Samhita YouTube channel. It also covers the small publishing tool ("the tool") that I use to manage that channel through the YouTube API Services.

## Who runs this

Stotra Samhita is a personal, non-commercial educational project run by Karthik Raman, Chennai, India. You can contact me at stotrasamhita@gmail.com.

## Use of YouTube API Services

The tool uses the YouTube API Services, but only on my own YouTube channel. It uploads my own videos and sets their titles, descriptions, thumbnails, playlists and caption tracks.

By using this tool you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## What data is collected

- **Visitors to this website and viewers of the channel:** this site does not ask you to sign in and does not collect personal information through the YouTube API Services. GitHub Pages, which hosts this site, may keep standard server logs; see GitHub's privacy statement.
- **The tool:** the only account that signs in to the tool is the channel owner's. It does not access, collect, store or share any other user's YouTube data.
- **Authorisation token:** the OAuth token that the tool uses for my own channel is kept privately in my own working environment. It is never published or shared.

## How data is used and shared

The tool uses the YouTube API Services only to publish and organise my own videos. I do not sell, rent or share any YouTube API data with third parties, and I do not use it for advertising.

## Storage and deletion

The tool does not keep copies of YouTube API data beyond what it needs to finish a publishing run. Access can be revoked at any time from the [Google security settings page](https://myaccount.google.com/permissions), after which the stored token stops working and is deleted.

## Cookies

This site does not set its own cookies. Embedded YouTube videos may set cookies under Google's policies.

## Changes

If this policy changes, I will update this page and the date at the top.
