# Mahabharatam

Srimad Mahabharatam in Sanskrit (Kumbhaghonam edition), built from the
[Mahabharatam](https://github.com/stotrasamhita/Mahabharatam) TeX corpus. One
parva (Virata Parva) uses an alternate source file pending a small parser
feature; the rest of the corpus converts cleanly.
